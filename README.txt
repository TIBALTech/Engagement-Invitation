NAVEENKUMAR & SONA - ENGAGEMENT INVITATION

Opening card:
- Premium navy-blue and gold Tamil invitation design
- No gopuram on the opening card
- N & S ring button opens the main invitation
- Tap to Open with Music also opens the main invitation

Main invitation:
- Detailed Tamil Nadu temple gopuram hero
- No top navigation
- Couple section
- Engagement label (no Grand Portrait / Ring Exchange)
- Countdown
- Event details
- Family invitation
- Venue and Google Maps
- Invitation message as the final major section

To run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Optional: place a Nadaswaram audio file named music.mp3 in the same folder.
4. Replace assets/couple-portrait.jpg or assets/temple-hero.jpg if you want different images.
